# Keyboard shortcuts

On macOS use `⌘` where this page says `Ctrl`.

## App

| Shortcut | Action |
| --- | --- |
| `Ctrl K` or `Ctrl P` | Search pages and run commands (`>`) |
| `Ctrl J` | Ask AI (on a selection, at the cursor, or open the chat) |
| `Ctrl G` | Graph view |
| `Ctrl Alt N` | New page |
| `Ctrl \` | Show or hide the sidebar |
| `Ctrl S` | Save now (pages also save automatically) |

## Editing

| Shortcut | Action |
| --- | --- |
| `/` | Insert a block |
| `[[` | Link to a page |
| `Ctrl B` / `Ctrl I` | Bold / italic |
| `Ctrl E` | Inline code |
| `Ctrl Shift H` | Highlight |
| `Ctrl K` (with text selected) | Add a link |
| `Ctrl Z` / `Ctrl Shift Z` | Undo / redo |
| `Tab` / `Shift Tab` | Indent / outdent list items |

## Teams

| Shortcut | Action |
| --- | --- |
| `Ctrl Alt M` | Comment on the selection |
| `Ctrl Enter` | Send a comment |
