# Local Notes documentation

Local Notes is a calm, Notion-style editor for plain markdown files. Your notes live in a normal folder on your computer — your **vault** — and every page is a `.md` file you own. It works with your Obsidian vault, adds a graph view and backlinks, an optional AI assistant, and a self-hosted server for teams.
