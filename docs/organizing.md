# Organizing

## Folders and pages

The sidebar mirrors your vault folder. Hover a row for its `•••` menu and `+` button, or right-click it.

- **New page** — `Ctrl Alt N`, the sidebar `+`, or the Home screen.
- **Rename** — edit the page title, or **Rename** from the row menu. The file is renamed on disk.
- **Move** — drag a page onto a folder.
- **Delete** — moves the page to the vault's `.trash` folder (the same place Obsidian uses), so it's recoverable.

## Pages inside pages

Drag a page onto another page, or choose **Add subpage**, to nest it — just like a wiki. On disk this is stored as `Page.md` plus a folder `Page/` holding its subpages, which Obsidian reads too. Renaming, moving or deleting a page takes its subpages with it.

Parent pages list their **Subpages** at the bottom, and breadcrumbs at the top show where you are.

## Favorites

Star a page (top-right) to pin it to **Favorites** at the top of the sidebar.

## Search and commands

Press `Ctrl K` (`⌘ K`) to search page names and content across your vault. From the same box you can:

- press `Ctrl Enter` to create a page with the text you typed
- type `>` to run commands — new page, today's note, graph view, AI, theme and more

## Changes from other apps

Edit your files in Obsidian, a text editor or a sync tool and Local Notes picks up the changes when you come back to the window.
